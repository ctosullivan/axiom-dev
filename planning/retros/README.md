# Retrospectives

One file per completed phase/stage, added when that phase/stage actually
completes (see `AGENTS.md` §6 — completion requires independent closeout
evidence, not just finished work). Format per the bootstrap prompt: intended
outcome, actual outcome, verification evidence, unexpected findings,
process overhead, lessons learned, recommended methodology improvements.
Proportionate to the scope of the work — see `decisions/0001` for why this
deliberately does not follow CodeCompass's per-phase multi-file audit
taxonomy.

`phase-1-stages-1.0-through-1.5.md` is the first entry — written before
Phase 1 is marked Completed, because the bulk of the work and its most
useful findings were already behind the session and the phase's own
closeout assessment (`evidence/phase-1-closeout.md`) recommends leaving
it open on two named blockers, not because it's finished. The file says
so explicitly in its own status note, rather than implying completion by
existing.
